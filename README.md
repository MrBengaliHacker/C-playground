## 📖 About

**C-Playground** is a collection of C programs arranged as a step-by-step learning path. It starts with the basics, moves through control flow, loops, patterns and functions, and finishes with linked lists and sorting algorithms.

Most topic folders include their own `README.md` with the problem statement, the solution code and an explanation. This makes the repository useful for students learning C, quick revision before exams, and beginners building up to DSA practice.

## 🗂️ Repository Structure

```text
C-playground/
├── 1. basics/             # Hello World, escape sequences, comments, variables
├── 2. arithmetic/         # Arithmetic operations, swapping, averages
├── 3. if_else/            # Conditional logic and decision making
├── 4. ternary_operator/   # Compact conditional expressions
├── 5. switch_case/        # Multi-way branching
├── 6. loops/              # Iteration and number-based problems
├── 7. pattern/            # Star patterns with nested loops
├── 8. functions/          # Modular code with functions
├── Linked List/           # Singly linked list implementations
├── sorting/               # Classic sorting algorithms
├── .gitignore
└── README.md
```

## ⚙️ Getting Started

### Prerequisites
- A C compiler such as [GCC](https://gcc.gnu.org/) (MinGW on Windows) or Clang
- Any editor or IDE (VS Code, Code::Blocks, etc.)

```bash
gcc --version
```

### Clone the repository
```bash
git clone https://github.com/MrBengaliHacker/C-playground.git
cd C-playground
```

### Compile and run
Folder names contain spaces, so wrap paths in quotes.

```bash
gcc "6. loops/prime_number.c" -o prime

# Linux / macOS
./prime

# Windows
prime.exe
```

## 🎯 Suggested Learning Path

1. **Basics and arithmetic:** get comfortable with syntax, variables and I/O.
2. **If–else, ternary, switch:** learn control flow and decision making.
3. **Loops and patterns:** build logical thinking with iteration.
4. **Functions:** write modular, reusable code.
5. **Linked list and sorting:** move on to data structures and algorithms.
